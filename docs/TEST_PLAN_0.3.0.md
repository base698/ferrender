# Ferrender 0.3.0 manual test plan

This is a **test build awaiting your verification**, not a published release. Run the numbered checks below and report **Pass**, **Fail**, or **Unsure** by number. Allow about 60–90 minutes; you can stop between sections. None of these entries is a claim that a person has already completed the test.

Save open work, quit older Ferrender windows, and open the supplied 0.3.0 test app. Use separate test files and keep your existing designs unchanged. Check **Help → About Ferrender → Copy build info**: it should say **0.3.0-dev**, with the commit matching the test bundle's build information. Record the commit and whether the build includes local changes.

## Components

1. **Create and activate a component.** In a new millimeter document, choose **Model → New Component** or the **Component** toolbar button. Rename it `Bracket`. Confirm it becomes active, its name appears in the status bar, and its browser node contains Origin, Construction, Sketches, and Bodies sections. Draw a 20 × 10 mm rectangle on its XY plane and extrude 10 mm as New Body. Expect the sketch, extrusion, and `Body1` to belong to Bracket.
2. **Keep overlapping components separate.** Choose **Model → Activate Root**, then create another component named `Insert`. Draw the same 20 × 10 mm rectangle at the same coordinates and extrude 10 mm with **Join**. Expect two overlapping bodies, one in each component, with a `Body1` in each. Hide Bracket to inspect Insert. A Join in Insert must not consume Bracket's body.
3. **Scope a cut.** With Insert active, make a circle inside its rectangle and cut through all. Expect only Insert to have the hole. Hide Insert and show Bracket: its original box must remain intact. Undo the cut and Redo it. Check the browser and timeline still show the correct ownership.
4. **Nest and hide a subtree.** Activate Bracket, create a child named `Pin`, and make a small separate body in it. Hide Bracket: Bracket and Pin must both disappear, while Insert remains visible. Show Bracket: both return. Hide only Pin: Bracket must remain visible. Save and reopen; confirm nesting, visibility, and the active component survive.
5. **Move the whole component.** Select Bracket's component node and choose **Move**. Enter Translate X `30 mm` and Rotate Z `90 deg`; accept. Expect Bracket and Pin to move together, while Insert stays in place. Undo and Redo. Moving the component should edit its placement, without adding an ordinary body Transform feature. Select a body instead and open Move to confirm the body and component choices are distinct.
6. **Model on a moved face.** Keep Bracket moved and rotated. Click a flat face of its body and start New Sketch. Draw a small circle and extrude it outward 3 mm. Expect the new feature to start exactly on the visible face and remain in that component. Move Bracket again: the new feature should travel with it. Check Measure and exports use the visible, placed positions rather than the original origin.
7. **Pattern and explicit Combine.** In a separate copy, pattern an Insert body; copies should belong to Insert. Position a tool body from another component so it overlaps the target and use **Combine** explicitly. Expect the result to stay in the target's component. With Keep Tools off, the consumed tool must disappear from its component; with Keep Tools on, it must remain. Undo should restore the original ownership and bodies.
8. **History and deletion.** While a child component is active, roll the timeline back before its creation. Expect its body to disappear and the active component to return to root with an explanation. Restore the marker to the end. Suppress a parent component: its descendants must not build; unsuppress it to restore them. Delete a parent from a saved copy: the confirmation should identify the subtree being removed, and other components should survive. Undo should restore the subtree. During marker dragging the model should remain unchanged until drop, as in 0.2.2.

## Construction planes

Use a fresh root-only document for tests 9–14. Make a **40 × 20 × 10 mm box** with its bottom on XY and save it as a reusable starting point. The Plane toolbar button and **Model → Construction Plane** open the same tool. Rotate the view as necessary to pick faces clearly.

9. **Offset from a face and use the plane.** Open Construction Plane, choose **Offset**, pick the box's top face, and enter Distance `5 mm`. Expect a preview 5 mm above the face and a new item under Construction after OK. Start New Sketch on that plane, draw a 6 mm diameter circle above the box, and extrude 3 mm as New Body. The post should span Z = 15–18 mm. Edit the box's original extrusion from 10 to 20 mm: the plane and post should move to Z = 25 and Z = 25–28 mm. Undo/Redo should restore/reapply the change.
10. **Edit offset, arrow, parameter, and To face.** In the offset dialog, drag the arrow and check the displayed distance and preview move together. Try `-3 mm` from the top face: the plane should be inside the box. Create parameter `gap = 5 mm`, set the distance to `$gap`, then change gap to 8 mm; its dependent sketch and post should move by 3 mm. Use **To face** to set the offset from one parallel box face to the opposite face. Confirm the preview lies on the chosen target face. Try a perpendicular target face: expect a message asking for a parallel face, with the previous distance unchanged. Cancel a further edit and verify the original plane is unchanged.
11. **Midplane and Flip.** Create a Midplane between the top and bottom faces. Expect it at half the box's height. Start a sketch on it and make a 4 mm symmetric cut; inspect a section or side view to confirm it is centered. In a fresh copy, choose top and side faces instead: expect a 45° bisector through their shared edge. Flip should choose the other bisector. Selecting the same face twice should show an error and create nothing.
12. **Three Points.** Create a plane from three noncollinear box corners that are not all on one box face; for the 40 × 20 × 10 box, use `(0,0,0)`, `(40,0,0)`, and `(0,20,10)` if entering coordinates. Expect the plane to pass through all three points. Start a sketch on it and make a small extrusion or cut. Repeat using three picked vertices, then a visible sketch point as one reference. Editing that source sketch point should move the plane. Three collinear or repeated points should be refused without changing the previous model.
13. **Picking, visibility, and chaining.** Create an Offset from another construction plane. Change the first plane's distance and confirm the second follows. Pick a construction plane from both the browser and viewport to start a sketch. Finish a sketch on a plane whose eye you have never toggled: it should hide automatically. Show it explicitly with its eye, make and finish another sketch on it: it should remain visible. Hidden planes must not intercept picking; a body in front of a plane must receive the click. The rectangle's edges must not become sketch geometry. Try selecting a construction plane with a nonzero quick Offset in New Sketch: expect an instruction to clear it or create another Offset plane. Clear it or enter zero, then select again: the sketch must stay attached.
14. **Broken references must be clear.** Save a copy and delete the original box extrusion. Its face-based planes should show errors, as should their dependent sketches and modeling features. The dependent solids must not silently remain at their old positions. Undo should restore the model. Separately suppress a source plane and restore it; its dependent solids should disappear and then rebuild. A failed plane should have an actionable message when inspected or edited. Also create a body Move after a plane, then edit the earlier plane: face picking and preview must show the body as it was when that plane was created; accepting must preserve the later Move.

## Combined checks and regression

15. **Planes inside moved components.** In a component, create an offset from its XY origin and a sketch/extrusion on it. Translate and rotate the component; its plane, sketch, and body should move together. Edit its plane distance and confirm the change follows the component's local normal. Create a plane referencing a face in a different moved component; moving that source component should update the reference correctly. Nothing should jump back to the document origin when picked or edited.
16. **Save, reopen, and export.** Save a document containing nested components and each plane kind. Reopen it and check names, active component, placements, visible state, parameter expressions, and sketch attachments. Export visible bodies to STL and STEP; check the files include the intended placed solids and omit hidden subtrees and plane rectangles. A component-filtered API export, if you test it, should contain only that subtree. STEP is a flat collection of solids, not an assembly hierarchy. Open a copy of a new-feature `.ferr` in 0.2.2: expect the readable “newer version” refusal.
17. **Existing designs and sketch tools.** Open a known-good bishop, rook, or pawn from 0.2.2. Check dimensions and exports. Quickly recheck endpoint-first three-point arcs, Dimension on an existing line, a persistent Shift angle lock, moving/scaling a reference image, open-end highlighting, invalid expression feedback, and Light/Dark/System appearance. Reopening an older design must not create extra components or change its shape.

## Report a failure

Send the number, copied build info, exact inputs, expected result, actual result, and any error text. Save the smallest `.ferr` that reproduces it; include a screenshot for picking, placement, visibility, or layout problems. Say whether the action was refused, made the wrong shape, or changed unrelated geometry. Keep any failed example so it can become a regression test.

A public 0.3.0 release is deliberately held until you have reviewed this test build. Passing automated tests does not replace these human checks.
