# Projection and corner-pattern retest

Run this before continuing the main 0.3.0 acceptance plan. Use the updated **0.3.0** app and compare **Help → About Ferrender** with the supplied build information. Save your work and restart the app to load the updated build. These steps remain available for regression testing after release.

The problem was profile selection: Extrude automatically included a projected plate outline along with a circle. New Body created a separate body containing both extrusions, producing an overlapping plate. Pattern correctly repeated that whole feature. Multiple closed regions now require an explicit area choice; a normal click replaces the selection, and Shift-click adds or removes regions. The Project tool still creates geometry that can be deliberately selected for extrusion.

1. **Repair an existing example.** On a copy of an affected design, double-click the circle's extrusion in the timeline. Click inside the circle where it extends outside the plate. Expect **Profiles: 1 selected**. Choose **New Body**, retain the distance, and accept. Hide the original plate in the browser: only one cylinder should remain. Show it again. Undo should restore the old selection; Redo should restore the cylinder-only result. New Body may geometrically overlap another body; it must remain separately hideable and must not include an extra plate.
2. **Recreate the reported workflow.** In a separate file, make a 60 × 50 mm plate, 21 mm thick. Start another XY sketch and Project the plate face. Draw a 22 mm diameter circle centered on the corner `(0, 50)`. Open Extrude: expect no region selected. Click the circle, choose New Body, and extrude 21 mm. Expect two bodies: the unchanged plate and one 22 × 22 × 21 mm cylinder. Repeat with a circle entirely inside the outline: the plate must still not be chosen automatically.
3. **Check deliberate multiple selection.** In the extrusion dialog, click the plate region, then click the circle normally: the selection should change to the circle only. Shift-click the plate region to select both; Shift-click it again to remove it. Clear Profiles should remove the whole selection. Cancel to avoid keeping the deliberately overlapping result.
4. **Fill four corners with one pattern.** Select the cylinder and open Pattern. Confirm Repeat names its extrusion. Choose **Linear**, **X**, Count **2**, Spacing **60 mm**. Enable **Second direction**, choose **Y**, Count 2 **2**, Spacing 2 **−50 mm**. Expect four positions including the original, at `(0,50)`, `(60,50)`, `(0,0)`, and `(60,0)`. Accept. Expect five separately hideable bodies: one plate and four cylinders. Hide the plate to confirm the copies contain no plate outlines. For another plate size, use its corner-to-corner distances and the signs appropriate to the starting corner.
5. **Edit and undo the grid.** Double-click the pattern chip. Change Spacing 2 to **−80 mm** and accept: only the second row should move, and no extra pattern feature should appear. Undo and Redo the edit. Undo the original pattern creation in a separate copy: all three copies should disappear together, leaving the plate and original cylinder.
6. **Save and reopen.** Save the grid, close it, and open it again. Expect the five bodies, two directions, counts, and signed spacings to remain. These new grid files need this updated candidate; an earlier candidate should refuse to open them clearly. Ordinary single-direction patterns and existing designs remain readable.

Report **Pass**, **Fail**, or **Unsure** by number, with copied build information. For a failure, keep the smallest saved `.ferr` that reproduces it. After these pass, continue the component movement and remaining checks in [the full test plan](TEST_PLAN_0.3.0.md). No acceptance pass is claimed here.
