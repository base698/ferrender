# Ferrender 0.3.0 test-build notes

**Testing candidate only. Not a published release.** User verification is required before tagging or publishing 0.3.0. Check **Help → About Ferrender → Copy build info** for **0.3.0-dev** and compare the commit with the test bundle's build information; a version number alone does not distinguish successive test builds.

The candidate work adds:

- **Open Recent:** File → Open Recent keeps the last 12 successfully opened/saved designs across restarts, with folder labels, the normal unsaved-work prompt, and Clear Recent. History lives in `~/.config/ferrender/recent.json` beside the existing settings, honoring the same directory overrides.

- **Safer solid cleanup:** face merging runs on an independent copy and is discarded if it changes volume. Boolean results also check display-mesh volume against the exact solid so broken periodic surfaces produce an error instead of a misleading accepted result.
- **Rounded-face extrusion:** new face-derived sketches preserve verified circular arcs and circles instead of cutting against polygon chords. This prevents thin remnants along circular fillets; existing saved outlines remain unchanged.
- **Command search:** press S to find modeling and sketch commands, including Text / Emboss; use arrows and Enter to choose. M opens Move for the selected body or component.
- **Components:** nested named containers for sketches, bodies, planes, and modeling features. The active component owns new work; Join, Cut, Intersect, and Through All are scoped to that component. Explicit Combine can reach across components.
- **Component placement and visibility:** move and rotate a whole component subtree, hide or show it, and preserve ownership through timeline changes, Undo, saving, and exports.
- **Construction planes:** Offset, Midplane, and Three Points features with persistent references. A sketch created on one follows its plane as parameters, source faces, or source points change.
- **Explicit extrusion profile selection:** sketches with multiple closed regions require an area selection, including projected outlines with new circles. Plain click replaces the selection; Shift-click adds or removes regions. New Body keeps the selected extrusion separate.
- **Native solid primitives:** editable Box, Cylinder, Sphere, Cone/frustum and Torus features under Model → Primitives, with parameter-driven sizes and placement, component-scoped operations, pattern support and exact STEP export.
- **Two-direction linear patterns:** rectangular grids with independent axes, counts and signed spacings, plus timeline editing of an existing pattern.
- **Direct body operations:** Remove records later removal while preserving earlier history and copies; Split divides exact bodies with an infinite flat plane; Join Bodies opens Combine.
- **Graphical placement:** X/Y/Z arrows and rotation rings/bars for bodies, components and primitives; Place in view for primitives; independent last-copy span handles for Linear pattern directions.
- **Sticky sketch capture:** a 10 px acquisition range and 18 px release range, with outward-flick/Alt release and persistent supported sketch relationships.
- **Browser and timeline controls:** component activation and nesting, a Construction folder, plane visibility, feature editing, and identification of feature ownership.

Native files that use components or construction planes use format 5. Two-direction linear patterns use format 6, so older candidate builds refuse them rather than silently drop the second direction. Primitive features use format 7; Remove and Split features use format 8. Use the matching 0.3.0 test build identified in About. Older files remain readable; plain documents continue to use the older compatible format when they do not need new features. Test with separate copies when comparing versions.

Joints, component instances, linked external components, STEP assembly structure, browser reparenting, moving an existing body between components are outside this candidate's scope. Component movement uses the placement dialog with graphical handles. Construction axes, tangent/angled planes, and construction planes as arbitrary mirror or To Face targets are follow-up work.

Use the [consolidated manual test plan](../TEST_PLAN_0.3.0.md), [components specification](../COMPONENTS_0.3.md), [construction planes specification](../CONSTRUCTION_PLANES_0.3.md), and [primitive guide](../PRIMITIVES_0.3.md), and [direct modeling guide](../DIRECT_MODELING_0.3.md). The separate specifications retain their detailed design rationale and acceptance cases.

## Validation status

The complete local macOS suite passes **303 tests**, with zero failures and three optional demonstration tests skipped. It covers components and planes; primitives, patterns and direct body operations; graphical placement and sticky capture; command search and keyboard isolation; rounded-face extrusion through both UI entry points; and Boolean volume checks. Search and modeling dialogs were rendered and inspected in Light and Dark appearances. Five new recent-file checks cover menu selection, persistence, ordering and deduplication, private writes, clear-without-delete, successful UI/automation open and save tracking, and preservation of unsaved work on cancelled or failed opens.

New component checks exercise nested Join/Cut isolation, parent/child rotations, picking and sketching on moved faces, inherited visibility, native save/reopen, visible-only STL/STEP export, and subtree Delete/Undo/Redo. Selecting a component or editing one of its sketches does not activate it: new sketch-based features belong to the active component. Direct face extrusion follows the picked body’s owner.

Eight focused geometry regressions cover circular face boundaries and holes, unequal end faces, component placement, preserving real chamfers, torus operations in both orders, empty intersection semantics, and legacy chord slivers. Removing the cleanup protection reproduces the damaged torus union; removing the mesh-volume safeguard reproduces an accepted invalid surface. The corrected reported design passes Join, Cut and Intersect in both target/tool orders with one closed solid each. Its original saved outline remains untouched; existing frozen sketches are not automatically migrated. Noncircular face boundaries still use sampled approximations.

The user has reported successful Remove/STL export, Split, moving/rotating separated and rejoined bodies, sketch capture, and sketch/extrude workflows on Offset and Three Points planes. These observations do not claim completion of every manual substep. Component checks 1–4 are accepted using the user’s Root/Bracket variation, including nested visibility and save/reopen. Remaining component checks and the new checks 34–39 still need human acceptance. Exact build identity, packaged/native checks, and corrected example files are recorded in the delivered test bundle. A public release remains held for that acceptance.
