Ferrender 0.2.2 improves the sketch interactions identified during manual testing:

- **3-Point Arc** now takes the start and end first, then a point on the desired bulge. Moving the third point controls the side and curvature while the endpoints stay put; type Diameter for an exact circle size.
- **Dimension** opens a selected item's value immediately. A clicked line opens Length without needing a blank-space click; existing curve sizes are edited rather than duplicated. Shift-select two items before Dimension for an angle or distance between them.
- Deliberate **Shift angle locks** remain as editable constraints after placement. Lines also accept a typed Angle; tangent arcs accept a typed Sweep. Ordinary snapping helps keep common directions and turns steady.
- **Select** can move reference images and scale them uniformly from corner handles while preserving rotation. Release commits one undoable edit; Escape cancels the drag. Sketch geometry takes priority when picking the image body.

The [focused 0.2.2 guide and manual retest plan](https://github.com/base698/ferrender/blob/v0.2.2/docs/SKETCHING_0.2.2.md) covers the changed interactions. The [full sketching guide](https://github.com/base698/ferrender/blob/v0.2.2/docs/SKETCHING_0.2.md) and [30 mm bishop tutorial](https://github.com/base698/ferrender/blob/v0.2.2/BISHOP_TUTORIAL.md) are updated for the new arc click order. The API's named arc points and existing saved arc shapes are unchanged. New line-direction or arc-sweep dimensions require 0.2.2 or later (file format 4); older designs remain readable.

Downloads include Apple Silicon and Intel Mac apps and Linux x86-64, plus checksums. Linux builds target Ubuntu 24.04 and require glibc 2.39 or newer. macOS builds are ad-hoc signed, not notarized. Use **Help → About Ferrender → Copy build info** to identify the exact source commit when testing.
