Ferrender's first packaged release includes parametric sketches, exact solids, revolve/extrude, patterns, threads, text and flat-face embossing, recovery, and the manual 30 mm bishop tutorial.

The timeline marker previews a position while held and rebuilds once on drop. Another drag waits until drawing finishes. Help > About Ferrender shows the precise source commit.

Downloads:

- **macos-arm64.zip** — Apple Silicon Mac app.
- **macos-x86_64.zip** — Intel Mac app.
- **linux-x86_64.tar.gz** — built and tested on Ubuntu 24.04; requires glibc 2.39 or newer and a desktop graphics driver.
- **SHA256SUMS.txt** — download checksums.

Each archive contains the native app, install instructions, build identity, documentation (including BISHOP_TUTORIAL.md and its diagrams), and bundled dependency notices. macOS apps are ad-hoc signed, not notarized; use the normal macOS approval flow when opening a downloaded build.

The release workflow tests the engine on all three platforms, runs the full offscreen UI suite on Linux, and makes a real CAD solid with each packaged executable before publishing.

The point-coordinate, new arc, reference-image, spline, and gap-highlighting improvements are planned for 0.2.0 and are not part of this baseline release.
