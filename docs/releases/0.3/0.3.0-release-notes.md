# Ferrender 0.3.0

Ferrender 0.3.0 adds components, persistent construction planes, solid primitives, and graphical placement tools, with fixes verified during manual modeling tests.

- **Components:** group sketches, bodies, planes, and features in nested components. Join, Cut, Intersect, and Through All operate within the active component. Move or rotate a complete subtree, inherit visibility, and preserve placement and ownership through saving, exports, and Undo. Explicit Combine can join bodies across components.
- **Construction planes:** create Offset, Midplane, and Three Points references. Sketches attached to a plane follow it as its references or dimensions change.
- **Solid primitives:** create editable Box, Cylinder, Sphere, Cone/frustum, and Torus features. Place them on origin planes, flat faces, or construction planes, then adjust their position and rotation graphically.
- **Body operations:** Remove hides a body from that point in history while preserving earlier copies; Split divides bodies using a flat face or construction plane; Join Bodies opens Combine.
- **Move and pattern controls:** use X/Y/Z arrows and rotation rings/bars. Linear patterns support two independent directions and draggable last-copy handles that can snap to sketch geometry.
- **Sketch capture:** points stick to nearby lines, circular curves, and supported endpoints. Move away, flick outward, or hold Alt to release. Supported relationships persist as sketch constraints.
- **Command search:** press **S**, type a command, and use arrows/Enter to select it. **M** opens Move; **V** selects in a sketch. Text / Emboss is available through search and the Model/Sketch menus for raised lettering and engraving.
- **Open Recent:** the File menu remembers the last 12 successfully opened or saved designs across restarts. Folder labels distinguish identical names; Clear Recent clears the list without deleting files. History uses `~/.config/ferrender/recent.json` beside existing settings and honors the same directory overrides.
- **Geometry fixes:** select extrusion profiles explicitly, including circles inside projected outlines. New face-derived sketches preserve circular arcs and circles, avoiding thin remnants when extending or cutting rounded faces. Solid cleanup preserves valid torus geometry, and checks reject severely inconsistent Boolean meshes instead of accepting damaged results.

## Compatibility and known limits

Older designs remain readable. Components and construction planes use file format 5, two-direction patterns use format 6, primitives use format 7, and Remove/Split use format 8. Older apps refuse unsupported formats rather than silently omit features.

Overlapping coplanar faces on separate bodies can still produce a striped or speckled display artifact. The bodies remain separate; hiding one or explicitly joining them removes the coincident surfaces. Existing saved face-derived sketches retain their stored outlines; the circular-boundary fix applies to newly created outlines. Noncircular curves can still use sampled approximations. Face references are recovered from position and bounds rather than persistent topological identities.

Component instances, joints, linked external components, reparenting existing bodies, and STEP assembly hierarchy are outside this release. STEP exports contain placed solids. Curved-face text wrapping is not supported.

## Verification and documentation

The local macOS suite passed **303 tests**, with zero failures and three optional demonstrations skipped. Coverage includes component isolation and placement, construction planes, body operations, command search, recent-file persistence, circular face outlines, and Boolean volume checks. Packaged and isolated native macOS checks covered opening, saving, restarting, and persistent recent history. Manual acceptance covered component checks 1–8 and the reported workflows in checks 34–39, plus the recorded plane and direct-modeling tests; this does not claim every optional substep was exercised by hand. Publication is gated on CI and all three native packaging jobs.
