Ferrender 0.2.1 adds dark mode with a saved appearance preference.

Choose **View → Appearance → System, Light, or Dark**. System is the default and follows operating-system appearance changes while Ferrender is open. Light and Dark override the OS until you choose System again. Your choice is remembered across launches.

Menus, dialogs, sketch geometry and labels, reference-image controls, the timeline, and the viewport background now adapt to both themes. Changing appearance leaves your design, history, camera, reference-image colors, and solid exports unchanged.

System mode reads the macOS appearance directly and uses the desktop settings portal on Linux. Allow a few seconds for OS changes to appear. If no preference is available, Ferrender uses Light; the manual choices remain available. Native file pickers may follow the OS independently.

See the [appearance guide and manual test plan](https://github.com/base698/ferrender/blob/v0.2.1/docs/APPEARANCE.md). The [0.2 sketching guide](https://github.com/base698/ferrender/blob/v0.2.1/docs/SKETCHING_0.2.md) and [30 mm bishop tutorial](https://github.com/base698/ferrender/blob/v0.2.1/BISHOP_TUTORIAL.md) remain included.

Downloads include Apple Silicon and Intel Mac apps and Linux x86-64, plus checksums. Linux builds target Ubuntu 24.04 and require glibc 2.39 or newer. macOS builds are ad-hoc signed, not notarized. Use **Help → About Ferrender** to identify the exact source commit when testing.
