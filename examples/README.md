# Printable examples

STL exports made with Ferrender. Open a file below for GitHub's mesh preview, then use **Download raw file** to save it for your slicer. Dimensions are in millimetres; import at 100% scale.

| Model | STL | Editable design or tutorial |
|---|---|---|
| Teacup | [teacup.stl](teacup.stl) | — |
| Toothbrush holder | [toothbrush-holder.stl](toothbrush-holder.stl) | [.ferr](https://westcot.io/files/ferrender/toothbrush-holder.ferr) |
| Sword | [sword.stl](sword.stl) | [.ferr](https://westcot.io/files/ferrender/sword.ferr) |
| Virtuo holder | [virtuo-holder.stl](virtuo-holder.stl) | [.ferr](https://westcot.io/files/ferrender/virtuo-holder.ferr) |
| Coffee holder | [coffee-holder.stl](coffee-holder.stl) | [.ferr](https://westcot.io/files/ferrender/coffee-holder.ferr) |

The teacup and four gallery models are unchanged copies of the downloads in [the Ferrender project post](https://westcot.io/projects/ferrender/), which includes interactive previews and print photos.

STLs contain the exported triangles. Use the linked native `.ferr` designs to work with editable sketches, parameters and feature history.
